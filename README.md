# My-own-game-engines
I developed custom mini game engines and published them on GitHub.
# 🚀 Hydra & Titan Engine (Archive)

Early prototypes, Python code generators, and initial iterations of the **Titan** game engine (written in C++ with LuaJIT and OpenGL support).

Built purely out of enthusiasm as an experiment in procedural architecture generation and large-scale engine building.

## 📦 What's inside (`Engine.7z`)
* **Hydra Alpha (1.0 – 1.2) & Beta (1.3 – 1.4):** Python scripts and project structure generators.
* **Titan B12 (Base, 50, 4500, CPP):** Early C++ iterations paving the way toward an X-Ray 1.6-scale architecture.

## 🛠 How to Unpack & Build
1. If you don't have 7-Zip installed, download the portable archiver archive (`7zip.zip`) included in this repo and extract it using standard Windows tools.
2. Unpack the main **`Engine.7z`** archive using 7-Zip.
3. To compile the C++ versions, run the included `.bat` build scripts (requires a MinGW / `w64devkit` compiler environment).
